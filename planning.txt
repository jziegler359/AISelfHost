           LOCAL SELF-HOSTED AI HUB - PROJECT ROADMAP & ARCHITECTURE PLAN
================================================================================

PROJECT GOAL:
A unified, self-hosted web interface and backend running locally that brings
together:
  1. Ollama LLM Text Chat (Llama 3.2, Mistral, Qwen, etc.)
  2. Local Image Generation (Stable Diffusion / ComfyUI / diffusers)
  3. Extensible Multi-Model & API Support (Local + optional external APIs)
  4. Clean, responsive web UI with chat history and model controls

  Integration Approaches:
    - Option 1 (Direct via run.bat + Gradio Client):
        Start Fooocus normally with run.bat (runs Gradio on port 7865).
        Use `gradio_client` in Python to send generation tasks programmatically.
    - Option 2 (Dedicated REST API via Fooocus-API):
        Clone/download `Fooocus-API` which runs on FastAPI/port 8888.
        Provides clean REST endpoints (POST /v1/generation/text-to-image)
        and reuses your existing models and python_embeded without duplicating files.

  2.3 Backend Image Route:
      - Endpoint `/generate-image` in `pythoncode.py` that dispatches generation
